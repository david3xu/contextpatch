# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

**Read [`AGENTS.md`](AGENTS.md) — it is the operating rules for this repository.** Commands, crate
boundaries, the repository-authority invariant, the tool registry, conventions, and the
documentation contract all live there.

This file exists only so that Claude Code loads those rules. `CLAUDE.md` was renamed to `AGENTS.md`
in `342211a` because the rules are the project's rather than one vendor's, and that rename stands.
Do not copy content back here: a rule stated in two files is a rule that will disagree with itself,
which is the defect class `AGENTS.md` is written to prevent. Add new rules to `AGENTS.md`.
